# SAP S/4HANA Configuration & Process Portfolio

This repository documents setting up organizational structures, mapping business processes, and resolving system errors.

## 📂 Repository Structure

* 🏢 **[Org. Structure](./Org.%20structure)** – The foundation. Includes configuration for Company Codes (FI) and the complete purchasing structure (Plants, Storage Locations, Purchasing Organizations).
* 📦 **[Materials Management (MM)](./MM)** – Configuration and execution of advanced Procure-to-Pay (P2P) processes:
    * Automatic PO creation from Purchase Requisitions (Auto-PO).
    * Evaluated Receipt Settlement (ERS) with automatic invoice creation.
    * MRP runs with automatic source determination and Scheduling Agreements.
* 🛠️ **[Troubleshooting Log](./TROUBLESHOOTING.md)** – A centralized issue log. I document the system errors (hard stops) I face, their root causes, and step-by-step SPRO solutions.
